# Book of Rust flakes

This is a collection of Nix flakes for Rust development.

## Topics

- No flake: Just install the Rust toolchain
- A devShell with `cargo` and `rustc`
- Specifying `stable`, `nightly` or both
- Providing a package
- Additional Rust targets (aarch64, wasm, embedded)
- Compiling for Windows
- Caching (Crane? How else?)
